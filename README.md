# ClassNav AI

### Find Your Class. Navigate Your Campus.

**Team:** KaiVERSE  
**Hackathon:** GenAI Sprint 1.0  
**Track:** 1 — Amazon PartyRock  
**Organised by:** AWS Student Builder Group, JIS University

## Overview

ClassNav AI is an AI-powered classroom navigation assistant designed to help university students find their classrooms across multiple buildings and floors.

The project uses Amazon PartyRock to interpret student timetables, identify upcoming classes, and match classroom numbers with structured campus location information.

## Problem Statement

University campuses often have multiple buildings and floors. Students, particularly newcomers, may struggle to locate classrooms when moving between classes.

Traditional timetables provide room numbers but rarely explain how to reach those rooms.

## Our Solution

ClassNav AI connects student schedules with campus room information to make classroom discovery easier.

### Core Features

- AI-powered timetable interpretation
- Current and upcoming class identification
- Building, floor, and classroom lookup
- Classroom search
- Location guidance using verified room information

## Technology Stack

- Amazon PartyRock
- Generative AI
- Prompt Engineering
- Structured campus and timetable data

## Project Workflow

1. Student provides their timetable.
2. The campus room directory provides building and floor details.
3. The AI interprets the student's schedule.
4. The system identifies the current and next class.
5. The student receives classroom location information.

## System Architecture

The prototype uses Amazon PartyRock for AI processing.

A proposed production version could use Amazon Bedrock, AWS Lambda, Amazon API Gateway, Amazon DynamoDB, Amazon S3, and Amazon Cognito.
